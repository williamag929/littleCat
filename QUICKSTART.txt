QUICK START GUIDE - Little Cat Pet Game
=====================================

STEP 1: Install Python Packages
================================
Open PowerShell and run:

cd c:\projects\littleCat
pip install -r requirements.txt

This installs:
- pygame (for graphics and game loop)
- numpy (for math operations)
- scikit-learn (for machine learning utilities)


STEP 2: Run the Game
====================
In PowerShell:

python src/game.py

You'll see your cat appear on screen! It will be named "Whiskers" by default.


STEP 3: Learn the Controls
===========================

INTERACTION KEYS:
  P - Play with your cat
  F - Feed your cat  
  T - Pet/Show affection
  S - Let cat sleep
  H - Cat hides (punishment)
  R - Cat rests

GAME KEYS:
  E - Export cat's learned brain (save)
  L - Load a previously saved cat
  ESC - Exit game

STATS YOU'LL SEE:
  Happiness - How happy the cat is (increases with play/affection)
  Hunger - Food need (increases over time, decreases when fed)
  Energy - Tiredness level (decreases with activity, increases with sleep)
  Trust - How much cat trusts you (increases with consistent affection)


STEP 4: Train Your Cat
======================
Your cat LEARNS from interactions:

1. When you interact, the cat's BRAIN gets trained
2. The cat learns which actions get rewards
3. Over time, the cat's behavior adapts to your style
4. The cat's "mood" changes based on trust and happiness
5. The cat remembers your interactions

EXAMPLE POSITIVE TRAINING:
- Repeatedly play (P) when the cat is awake
- Feed (F) when the cat is hungry
- Pet (T) often to build trust
- Let cat sleep when energy is low

After a few days of consistent interaction, you'll notice:
- Cat takes certain actions automatically
- Cat's preferences become predictable
- Cat becomes happier and more trusting


STEP 5: Advanced - Run Training Script
=======================================
To test the AI without the game:

python src/trainer.py

This script:
- Trains cats with different interaction styles
- Shows learning metrics
- Compares positive vs neglected cat outcomes
- Exports detailed training logs


STEP 6: Customize Your Cat
===========================
Edit files to customize:

config.py:
- Change initial emotional states
- Adjust learning speed
- Modify action effects

cat_brain.py:
- Tweak learning algorithms
- Add new behaviors
- Modify memory system

game.py:
- Change visual appearance (draw_cat function)
- Add new interactions
- Modify UI layout

KEY LEARNING CONCEPTS
====================

1. REINFORCEMENT LEARNING
   Your actions = rewards/punishments
   Cat learns what works best

2. STATE MACHINES
   Cat has emotions that change based on interactions
   Each emotion affects cat's decisions

3. PATTERN RECOGNITION
   Cat learns behavioral patterns
   Predicts what human will do next

4. MEMORY SYSTEM
   Last 100 interactions are remembered
   Older memories fade naturally

5. DECISION MAKING
   Cat weighs current needs vs learned behaviors
   Uses confidence scores to decide actions


TROUBLESHOOTING
===============

Game crashes on start:
  → pip install pygame --upgrade
  → Make sure Python 3.8+ is installed

Cat not learning:
  → Make sure you interact consistently
  → Check that rewards are positive (check console output)
  → Try 50+ interactions for visible learning

Cat won't load:
  → Delete data/cat_brain.json and start fresh
  → Make sure data/ folder exists

Slow performance:
  → Close other programs
  → Reduce FPS in game.py if needed


TIPS FOR BEST RESULTS
====================

1. BE CONSISTENT - Train the same way each day
2. MIX INTERACTIONS - Play, feed, pet, sleep cycle
3. WATCH THE STATS - Learn what each stat means
4. SAVE REGULARLY - Export cat brain (E key) to backup
5. EXPERIMENT - Try different training styles
6. PATIENCE - AI improves over days, not minutes
